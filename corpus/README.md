# About this test corpus

All documents in this folder are entirely fictional. Firm name, client names,
case reference numbers, dates and amounts do not exist and were invented for
this test (AGT-013 project, 01.08.2026 / 03.08.2026). No real client data, no
leaked or real documents. Any resemblance to real people or cases is
coincidental.

The documents are in German (fictional German law-firm case files) -- the
code and this README are in English. See `../README.md` for why this corpus
exists and what it is used to prove.

Original disclaimer kept for the record: `00_hinweis.md`.
